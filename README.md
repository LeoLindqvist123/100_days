## 🧠 Key Learnings

Running notes on concepts that stuck:

* **Day 1–5:** Python is readable by design – indentation isn't just style, it's syntax.
* **Day 6–7:** Breaking problems into functions makes everything cleaner and reusable.
* **Day 8–10:** Dictionaries, functions and control flow can be combined to build increasingly complex programs.
* **Day 15–17:** OOP becomes much clearer when comparing procedural code with classes and objects.
* **Day 18–23:** Building games with Turtle Graphics helped me understand object state, inheritance, coordinates and event-driven programming.
* **Day 24:** File handling, directories and paths are essential when working with real-world data and automation.
* **Day 25:** Pandas makes working with structured data much easier, especially when loading and exploring CSV files using DataFrames and Series.
