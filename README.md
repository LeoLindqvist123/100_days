## 📌 About

This repo documents my journey through the 100 Days of Code Python Bootcamp.  
Each day has its own folder with the project code and a short note on what I learned.

**Why I'm doing this:** To build a solid Python foundation alongside my MLOps studies and have a public track record of consistent work.

## 🧠 Key Learnings

Running notes on concepts that stuck:

- **Day 1–5:** Python is readable by design – indentation isn't just style, it's syntax.
- **Day 6–7:** Breaking problems into functions makes everything cleaner and reusable.
- **Day 8–10:** Dictionaries + functions together are incredibly powerful for game logic.
- **Day 15–16:** OOP clicks when you rebuild the same project procedurally first, then with classes.
